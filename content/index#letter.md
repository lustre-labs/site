## Frontend shouldn't be surprising

Returning to a project six months later usually means catching up on the New Way
™️ to do things and a generous helping of "wait how does this work again?" We
designed Lustre to be different. 

Every Lustre application follows the same architecture. That means revisiting
and old project, joining a new team, or perhaps trying out Server Components
uses the same familiar building blocks.

If you've been put off trying frontend, maybe Lustre is just what you need!
